Importing from Aspen Plus

Aspen Capital Cost Estimator (ACCE) can load process data directly from Aspen Plus simulations. Supported input formats include compound files (.apw, .apwz) and Aspen Plus XML files.

Workflow

  1. Set the Simulation Type to "Aspen Plus" in the Project Basis.
  2. Browse to the simulation file and run Load Data.
  3. Map the loaded unit operations to size and cost the equipment.
  4. Run Evaluate to produce the project cost.

After mapping, icons in the process view turn green when components are successfully recognized and sized.
