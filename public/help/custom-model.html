Activating Custom Models

Custom models let you override the default mapping and use simulator stream data when sizing equipment such as reflux pumps and towers.

Enabling Custom Model Mode

  1. Open Tools - Preferences and select the Process tab.
  2. Check "Activate Custom Model" and confirm the preference window.
  3. Inspect the relevant streams (for example ICP-REF and ICP-REFEX) in the Project Basic View to read liquid flow rate, design gauge pressure, and design temperature.
